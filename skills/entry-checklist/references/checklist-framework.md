# 점검 영역 프레임워크

항목은 확인 대상의 목록이다. 항목에 적힌 내용은 사실 주장이 아니므로, 사실로 쓰려면 반드시 출처로 확인한다.

## 공통 영역

| 영역 | 확인할 것 |
|---|---|
| 시장 접근 | 해당 업종에서 외국인 투자가 허용되는지, 지분율 제한이나 조건이 있는지 |
| 설립·등록 | 사업 형태별 설립 절차, 필요 서류, 등록 기관, 최저자본금 요건 유무 |
| 업종별 인허가 | 품목에 필요한 허가, 등록, 인증(식품, 화장품, 의료기기, 전자제품, 금융, 교육 등) |
| 수입·통관 | 수입 허가, 품목 분류, 관세, 표시 의무, 현지어 라벨 요건 |
| 세무·회계 | 법인세, 부가가치세, 원천세, 이전가격 문서, 회계 기준과 감사 의무 |
| 외환·송금 | 배당과 로열티 송금 절차, 외화 보유와 환전 제한, 신고 의무 |
| 노동·고용 | 외국인 취업 허가와 체류 자격, 현지인 고용 비율 요건, 사회보험 |
| 데이터·개인정보 | 개인정보보호 법령의 존재와 시행 시점, 데이터 현지 저장 요건 |
| 전자상거래·플랫폼 | 온라인 판매 시 등록, 플랫폼 입점 규정, 광고 규제 |
| 지식재산 | 상표 선출원 여부, 등록 절차, 상표 선점 사례 점검 |
| 계약·분쟁 | 준거법과 분쟁 해결 방식, 합작 계약에서 정해야 할 사항 |
| 환경·안전 | 환경 영향 평가, 공장·창고 인허가, 폐기물 규정 |

## 국가별로 먼저 찾아볼 키워드

아래는 확인 대상의 이름이다. 현행 여부와 내용은 검색으로 확인한다.

### 인도네시아

- 투자 허용 업종 구분 체계(우선투자목록 등)와 업종 코드
- 온라인 사업자 등록 시스템(OSS)과 사업자등록번호(NIB)
- 식품, 화장품, 의약품 등록 담당 기관
- 할랄 인증 의무 대상 품목과 시행 일정
- 개인정보보호법 시행 여부와 후속 규정

### 베트남

- 투자등록증(IRC)과 기업등록증(ERC)의 단계별 절차
- 외국인 투자 조건부 업종 목록과 시장 접근 조건
- 전자상거래와 개인정보 관련 시행령
- 정부 조직 개편에 따른 담당 부처 명칭 변경 여부
- 외국인 노동허가 요건

## 항목 상태 정의

- 확인: 신뢰 등급 A 또는 B 출처로 현행 내용을 확인함
- 미확인: 출처를 찾지 못했거나 현행 여부를 확인하지 못함
- 해당없음: 업종이나 진출 형태상 적용되지 않음
- 충돌: 출처끼리 내용이 다름
