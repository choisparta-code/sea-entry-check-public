# 진출 규제·인허가 체크리스트

베트남·인도네시아 진출 계획에 대해 영역별 점검표를 만든다. 모든 항목은 확인된 출처에 묶는다. 확인하지 못한 항목은 지어내지 않고 "미확인"으로 남긴다.

## 1. 입력 확인

`../../references/practical-output.md`의 입력 가이드와 실무 결과 형식을 먼저 읽는다. 나라·요청·간략 상황으로 시작하며 요청 유형에 맞는 누락 정보만 질문한다. 아래 시장 진출 정보는 진출 요청일 때 적용한다.

- 국가: 베트남, 인도네시아 (둘 다면 국가별로 따로 점검)
- 업종 또는 취급 품목
- 진출 형태: 현지 법인, 지점·사무소, 합작, 유통 파트너, 온라인 판매 중 선택
- 조사 목적: 진출 가능성 판단, 인허가 일정 산정, 파트너 협상 준비 등

## 2. 점검 영역 적용

`references/checklist-framework.md`를 읽고 해당 국가·업종에 맞는 영역과 항목을 고른다. 해당 없는 항목은 "해당없음"으로 표시하고 이유를 한 줄 적는다.

## 3. 근거 확인

각 항목마다 현행 근거를 웹 검색으로 찾는다. 출처 선택과 신뢰 등급은 verified-research 스킬의 규칙과 `../verified-research/references/source-registry.md`를 따른다.

지켜야 할 규칙:

- 법령 조문 번호, 지분율 한도, 최저자본금, 처리 기한, 수수료 금액은 출처에서 직접 확인한 경우에만 적는다. 기억에서 꺼낸 수치는 쓰지 않는다.
- 부처 명칭과 사이트 주소는 개편으로 바뀔 수 있다. 접속해 확인한 것만 인용한다.
- 시행 여부와 개정 이력이 확인되지 않은 법령은 "시행 여부 미확인"으로 표시한다.
- 출처가 서로 다르게 말하면 임의로 하나를 고르지 않고 "충돌"로 표시한다.

## 4. 출력 형식

거래·세금·인력·통관 요청에는 `../../references/practical-output.md`의 세금·절차·근거·재검토 표를 적용한다. 아래 체크리스트만으로 마무리하지 않는다.

1. 요약 한 단락: 국가, 업종, 진출 형태, 확인된 항목 수와 미확인 항목 수
2. 영역별 표: 항목 | 상태(확인, 미확인, 해당없음, 충돌) | 요지 | 출처 번호
3. 출처 목록: 번호, 제목, 기관, 기준 연도, 주소, 신뢰 등급
4. 충돌과 미확인 목록: 무엇이 부족한지와 확인할 방법(담당 기관, 전문가 유형)
5. 현지 법무·세무 전문가에게 확인받아야 할 항목

이 체크리스트는 법률 자문이 아니라는 점을 결과 끝에 한 줄로 밝힌다.

## 5. 다음 단계 제안

사용자가 저장을 요청했거나 이미 승인했다면 research-record 스킬로 기록한다. 저장 의사가 없을 때만 제안한다.

MCP 연결 시 시작 전에 `../../references/live-workflow.md`를 읽고 공통 실행 절차를 따른다. 이미 시작한 조사라면 같은 runId를 이어 쓴다. 연결이 없으면 JSON 카드 작성은 가능하지만 실시간 저장·시각화가 수행됐다고 말하지 않는다.
