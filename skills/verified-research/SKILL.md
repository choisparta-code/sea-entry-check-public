# 출처 검증형 리서치

서술형 시장 브리핑 대신 "근거 장부"를 만든다. 모든 수치에는 값, 기준 연도, 기관, 신뢰 등급이 붙는다.

## 규칙

실무 검토는 `../../references/practical-output.md`를 읽어 적용 조건·계산 기준·절차·항목별 근거와 재검토를 함께 제시한다. 수치가 확인되지 않으면 필요한 자료와 확인처를 제공한다.

1. `references/source-registry.md`의 출처 목록과 신뢰 등급 정의를 따른다. 등급 A와 B 출처를 먼저 찾고, 없을 때만 C로 내려간다.
2. 수치 하나당 기록 항목은 다섯 가지다: 값, 단위, 기준 연도, 출처 기관, 신뢰 등급.
3. 등급 D 출처(블로그, SNS, 익명 게시글)는 단독 근거로 쓰지 않는다. 쓰게 되면 "참고용"이라고 표시한다.
4. 같은 지표를 두 출처 이상에서 찾아 비교한다. 값이 다르면 "충돌"로 표시하고 다음을 정리한다: 각 출처의 정의, 기준 연도, 통화와 환율 기준일. 차이의 원인은 확인된 것과 추정을 구분해서 적는다.
5. 기준 연도가 3년 넘게 지났으면 "오래된 자료"로 표시한다.
6. 통화를 환산했다면 환율 출처와 기준일을 적는다. 환산 전 원래 값도 함께 둔다.
7. 찾지 못한 수치는 빈칸으로 두고 "미확인"이라고 쓴다. 비슷한 나라나 업종의 수치로 채우지 않는다.
8. 사이트 주소는 실제로 열어 확인한 것만 적는다. 부처 명칭과 주소는 바뀔 수 있다.
9. 출처에 적힌 문장을 길게 옮기지 않는다. 요지를 자기 말로 쓰고 출처 번호를 붙인다.

## 출력 형식

1. 조사 질문과 범위 한 줄
2. 근거 표: 지표 | 값 | 단위 | 기준 연도 | 기관 | 등급 | 출처 번호
3. 충돌 표: 지표 | 출처 A 값 | 출처 B 값 | 차이를 설명하는 확인된 사실 | 추정
4. 신뢰도 요약: 등급별 출처 수, 오래된 자료 수, 미확인 수
5. 출처 목록: 번호, 제목, 기관, 기준 연도, 주소

수치의 정의·포함 범위·기준 기간과 출처 번호를 함께 남긴다. research-record의 v2 스키마에서 `metrics`를 사용하고 미확인 값은 `null`로 둔다. 출처가 여러 개면 `sourceRefs` 배열로 연결한다.

세금·지급·절차 조사에는 `../../references/result-view.md`를 읽어 확인된 규정 수치와 미확인 실제 적용을 각각 기록하고 세율 표·조건부 지급표·절차 그림에 근거를 연결한다. 지급표의 세율은 지급액에 적용하는 단일 공제율이어야 한다. 이익 법인세·누진 소득세·VAT를 같은 지급 공제율로 사용하지 않는다.

결론 후보와 사용자 확정 결론을 구분한다. 저장을 이미 요청한 경우 research-record 스킬로 바로 기록한다. MCP 연결 시 `../../references/live-workflow.md`의 공통 실행 절차를 따른다. 연결이 없으면 JSON을 제공하며 실시간 실행이 기록됐다고 주장하지 않는다.
