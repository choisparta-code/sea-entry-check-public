# SEA Research

베트남·인도네시아와 한국의 거래·인력·시장 진출을 검토하는 공개 플러그인 패키지를 준비합니다.

공식 Claude 및 ChatGPT·Codex 마켓 심사·게시 전입니다. 서비스 주소: https://sea-research-workbench.choisparta.workers.dev

사용자는 나라, 요청 사항, 간략 상황을 입력합니다. 결과는 조건부 수치·절차·근거·재검토 행동을 구분합니다. 서버는 별도 유료 모델 API를 호출하지 않습니다.

이 저장소에는 공개 설치용 파일만 추가합니다. 개인 조사 기록·원본 계약·비밀값·서버 인증 설정은 포함하지 않습니다.

지원 요청에는 오류 단계와 일반 오류 메시지만 적고 비밀번호·토큰·개인정보·비공개 계약을 게시하지 마세요.
