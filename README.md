# SEA Research · 0.3.1

베트남·인도네시아와 한국의 거래·인력·시장 진출을 조사하고 수치·절차·근거·재검토 행동을 개인 작업실에 남깁니다.

공식 Claude 및 ChatGPT·Codex 마켓 제출을 준비한 패키지입니다. 심사·게시 완료 전에는 공식 마켓 설치가 제공되지 않습니다. 저장소 등록과 공식 마켓 게시 상태는 별개입니다.

## 사용 방법

1. 지원하는 마켓에서 SEA Research를 설치하고 계정을 연결합니다. 본인 작업실의 자료 읽기·초안 저장 권한을 확인합니다.
2. **나라 > 요청 사항 > 간략 상황**을 채팅으로 설명합니다. 정해진 프롬프트나 도구 이름은 외울 필요가 없습니다.
3. 결과를 바꾸는 누락 정보만 추가로 답합니다. 이미 말한 사실은 다시 입력하지 않아도 됩니다.
4. 세율 표·조건부 지급액 표·절차 그림과 항목별 근거, 확인된 규정·사례 재검토를 확인합니다. 금액이나 적용 세율이 부족하면 계산 보류와 필요한 자료가 표시됩니다.
5. AI가 반환한 작업실 링크에서 진행과 기록을 보고 최종 결론을 직접 확정합니다.

예: `베트남, 한국 발주 개발·PM 계약 검토, 베트남 회사 직원이 한국에서 약 1년 수행`.

## 연결과 비용

작업실: https://sea-research-workbench.choisparta.workers.dev/workspace

이 패키지는 공개 HTTPS MCP 주소를 포함합니다. 설치 후 OAuth 로그인이 필요하며 별도 서버 프로그램을 설치할 필요가 없습니다. 같은 서비스 계정으로 웹과 AI를 연결하면 본인의 작업실을 사용합니다. MCP가 연결되지 않았거나 호출이 실패하면 실제 저장·실행을 완료했다고 주장하지 않습니다.

서버는 별도 유료 모델 API를 자동 호출하지 않습니다. AI 앱의 대화 사용량·요금은 사용자의 각 계정 조건에 따릅니다. 무료 시험 서비스는 공급자 한도·점검에 따라 제한될 수 있습니다.

## 포함한 스킬

| 스킬 | 역할 |
| --- | --- |
| entry-checklist | 상황별 질문과 규제·계약·세금·인력·통관 절차 검토 |
| verified-research | 수치·규정의 공식 근거·현행성·사례 적용과 충돌 확인 |
| research-record | 검증된 사실과 미확인을 구분해 초안·근거·재검토 행동 저장 |

0.3.1 시험판에는 웹 표시용 저장 계약이 추가됐습니다. 기존 설치자는 새 패키지로 업데이트해야 적용됩니다. 심사에 제출된 0.3.0과는 별도 버전이며 심사 승인·공개 게시를 뜻하지 않습니다.

실행 흐름은 `references/live-workflow.md`, 입력·결과 기준은 `references/practical-output.md`를 따릅니다. 근거 없는 수치는 미확인으로 남기며 세금 신고·법률 대리를 수행하지 않습니다.
